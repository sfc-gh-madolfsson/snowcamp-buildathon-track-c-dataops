# Skills map — what to reach for, by track

Type `/` in Cortex Code to invoke a skill. These are **hints**, not requirements — explore freely.

## Shared / all tracks
| Skill | Use it when you want to... |
|---|---|
| `/cortex-code-guide` | Learn what Cortex Code can do in your workspace and how skills work |
| `/sql-author` | Write/verify SQL against real tables (finds columns, avoids timeouts) |
| `/snowflake-diagnostics` | Understand roles, grants, warehouse/pool status, why access failed |
| `/developing-with-streamlit-in-snowflake` | Build + deploy the Final-Gate Streamlit app on SPCS |
| `/cortex-chart-customization` | Style charts consistently in agents or Streamlit |
